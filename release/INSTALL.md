# 安装与项目接入

候选源码版本 **0.4.0-alpha.6.47**，本轮仅面向 **Windows 版 Codex 桌面端**。需要已安装并打开的 Codex、现有 Python 3.11+ 与 GitHub 网络；可使用 Codex 已提供的 Python 绝对路径，无需更改系统 PATH。无需 Git、GitHub 登录或单独安装 Codex CLI；终端 CLI 会话不采集。

本版包含插件列表 Logo 与输入框图标；沿用 .46 的宿主运行绑定修复。固定标签安装入口在本版公开发布后可用。已发布旧版本附件保持不变。

## 1. 交给 Codex 安装

在 **Codex 桌面会话**中复制发送：

```text
请按 https://github.com/zemekeznb/blackbox-plugin/blob/v0.4.0-alpha.6.47/release/INSTALL-CODEX.md 为我安装并初始化 Blackbox，然后打开界面。暂不启用任何项目采集，不修改模型、账号或系统环境配置。
```

Codex 会读取对应版本的执行说明、检查依赖、下载并校验插件包，完成安装与本地初始化，再打开 Blackbox。候选修复把实际 Python 和物理状态目录保存在当前 Codex 的运行绑定中，供后续会话、MCP 与 Hook 共用。无需修改系统 PATH。插件登记、运行绑定、原生入口与本地网页打开分别报告；任一步失败都保留具体阻断。

### 插件尚未加载时

先让 Codex 检查正式插件的运行绑定和 `blackbox_reader` 实际启动错误。若只是当前会话尚未刷新，可按提示新开会话；确需完整重载时，先保存工作，完整退出并重新打开 Codex，然后发送：

```text
继续完成 Blackbox 的首次设置并打开页面，暂不启用任何项目采集。
```

安装只完成插件登记和运行初始化，不启用新项目、不授予 Hook 信任。更新时已有项目开关保持原状。

页面服务成功加载后，日常查看可在 **Codex 桌面端侧边栏**点击 **Blackbox**。也可以在 Codex 桌面会话中发送“打开 Blackbox。”。通过内置浏览器打开本地网页是独立结果，不能据此认定原生入口已可用。

## 2. 接入项目

- **首次接入：** 按 Blackbox 初始界面的引导，点击 **接入第一个项目**。
- **后续接入：** 点击页面左下角 **采集与隐私** → **使用与排查** → 展开 **如何接入新项目？**。

在对应入口阅读提示中的项目与保存范围，再把页面提供的接入提示词复制并发送到**目标项目的 Codex 桌面会话**。页面提示词是接入授权的统一入口，每个新项目都需要明确接入。

保存范围包括当前项目的可见输入、回复、工具调用及返回，可能含项目内容或敏感信息，默认不上传。Codex 会协助完成官方 Hook 审阅、启用该项目，并执行无副作用的真实命令检查记录。已有授权无需重复提供；需要重开时按给出的续验步骤继续，无需重启电脑。

**安装成功、项目已启用、真实记录已收到是三个不同状态。只有对应记录收到，项目接入才完成。**

## 遇到问题

将具体报错发回安装或接入的 Codex 会话，或提交[问题反馈](https://github.com/zemekeznb/blackbox-plugin/issues)。说明当前版本和失败步骤，先移除密钥与私人内容。

| 现象 | 下一步 |
| --- | --- |
| `python` 不存在、指向 Store 提示或版本不满足 | 让 Codex 查找已经提供的 Python 3.11+，用绝对路径执行并绑定；若没有可用解释器，报告缺失，不自动安装或修改系统 PATH |
| 无法定位 Codex，或发现多个宿主 | 打开目标 Codex 桌面应用；仍有歧义时让 Codex 检查，不另装 CLI 或随意选旧版本 |
| 网络访问或发行包校验失败 | 检查 GitHub 连接，将报错发回 Codex，按固定版本说明重试；不要跳过校验 |
| 安装源冲突 | 让 Codex 检查 Blackbox 安装源；若同一个 `personal` 源含其他插件，不删除整个源 |
| 安装完成但没有侧边栏入口或 Blackbox 工具 | 检查当前 Codex 的运行绑定及 MCP 实际启动错误，不反复重装，不安装 Probe 作为补丁 |
| 运行绑定失效或拒绝访问 | 报告失败阶段与系统错误码；必要时通过宿主单次权限机制取得所需访问，不关闭沙箱、不改 ACL、不换空数据目录 |
| 项目已启用但没有记录 | 检查 Hook 信任、运行配置与实际回执，必要时重载；不要以初始化成功代替采集验证 |

## 更新、停用与卸载

- **更新：** 先保存工作，并在 Codex 中让 Blackbox 停止阅读服务，再发送新版 README 的安装提示词。历史、阅读偏好和项目设置保留；需要重开时按提示继续。正在进行的长回合不保证无损热加载。
- **停用项目：** 在采集设置中停用指定项目，或让 `blackbox-review` 完成。关闭页面或停止阅读服务不会停用采集，停用不删除历史。
- **卸载：** 可先让 `blackbox-review` 将数据备份到仓库之外的新文件，再通过 Codex 插件管理卸载。普通卸载不删除本地历史、Python、Codex 或其他插件。

备份恢复、导出及隐私说明见[使用与隐私](ALPHA-GUIDE.md)。

## 已验证到哪一步

.45 收紧会话准入，防止安装辅助终端产生额外记录；升级后旧身份缓存会重新核对，已有历史不自动删除。其干净电脑测试暴露了后台 Python 启动和会话访问问题。候选修复必须在只安装正式插件、不依赖 Python PATH 的环境中，分别验证冷启动侧边栏、新会话打开、同一数据目录与真实记录收到。离线测试或浏览器页面成功不能替代这些结果；最低 Codex 版本与 API Key 登录模式仍需另行验收。

[Codex 执行说明](INSTALL-CODEX.md)供安装会话读取；[开发与验证](../docs/DEVELOPMENT.md)供维护者使用。

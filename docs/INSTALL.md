# 安装与项目接入

<!-- blackbox:published:start -->
当前版本 **0.4.0-alpha.6.46**，本轮仅面向 **Windows 版 Codex 桌面端**。先安装并打开 Codex，确保宿主能通过 `python` 调用 Python 3.11+，并能访问 GitHub。无需 Git、GitHub 登录或单独安装 Codex CLI；终端 CLI 会话不采集，CLI 使用支持留待后续补充。
<!-- blackbox:published:end -->

此指南的安装入口保持在已公开发布并通过下载验证的版本；准备中的版本不会提前切换这里的链接。

## 1. 交给 Codex 安装

在 **Codex 桌面会话**中复制发送：

<!-- blackbox:published:start -->
```text
请按 https://github.com/zemekeznb/blackbox-plugin/blob/v0.4.0-alpha.6.46/release/INSTALL-CODEX.md 为我安装并初始化 Blackbox，然后打开界面。暂不启用任何项目采集，不修改模型、账号或系统环境配置。
```
<!-- blackbox:published:end -->

Codex 会读取固定版本的执行说明、检查依赖、下载并校验插件包，完成安装与本地初始化，再尝试打开 Blackbox。无需自行操作终端或下载解压。插件登记、运行初始化、原生入口与本地网页打开分别报告；如果缺少依赖或遇到阻断，保留具体错误。

**当前 .45 已知问题：** 正式插件声明了侧边栏入口，但其后台页面服务依赖 `python` 命令。干净电脑上，安装会话临时使用其他 Python 可以打开本地网页，桌面后台仍可能因找不到 Python 而无法加载入口。运行绑定修复尚未发布，当前下载链接仍是原 .45 安装包。

### 插件尚未加载时

先让 Codex 检查正式插件 `blackbox@personal` 的 `blackbox_reader` 加载状态及具体启动错误。若只是当前会话尚未刷新，可按提示新开会话；确需完整重载时，先保存工作，完整退出并重新打开 Codex，然后发送：

```text
继续完成 Blackbox 的首次设置并打开页面，暂不启用任何项目采集。
```

安装只完成插件登记和运行初始化，不启用新项目、不授予 Hook 信任。更新时已有项目开关保持原状。

页面服务成功加载后，日常查看可在 **Codex 桌面端侧边栏**点击 **Blackbox**。也可以在 Codex 桌面会话中发送“打开 Blackbox。”。若通过内置浏览器打开本地网页，应报告为“本地网页已打开，原生入口尚未验证”，不能据此判定安装验收完成。

## 2. 接入项目

- **首次接入：** 按 Blackbox 初始界面的引导，点击 **接入第一个项目**。
- **后续接入：** 点击页面左下角 **采集与隐私** → **使用与排查** → 展开 **如何接入新项目？**。

在对应入口阅读提示中的项目与保存范围，再把页面提供的接入提示词复制并发送到**目标项目的 Codex 桌面会话**。页面提示词是接入授权的统一入口，每个新项目都需要明确接入。

保存范围包括当前项目的可见输入、回复、工具调用及返回，可能含项目内容或敏感信息，默认不上传。Codex 会协助完成官方 Hook 审阅、启用该项目，并执行无副作用的真实命令检查记录。已有授权无需重复提供；需要重开时按给出的续验步骤继续，无需重启电脑。

**安装成功、项目已启用、真实记录已收到是三个不同状态。只有对应记录收到，项目接入才完成。**

## 遇到问题

将具体报错发回安装或接入的 Codex 会话，或提交[问题反馈](https://github.com/zemekeznb/blackbox-plugin/issues)。说明当前版本和失败步骤，先移除密钥与私人内容。

| 现象 | 下一步 |
| --- | --- |
| `python` 不存在、指向 Store 提示或版本不满足 | 让 Codex 区分会话使用的解释器和桌面后台的启动环境；.45 的临时 PATH 设置不能修复后台入口，不自动安装 Python 或修改系统 PATH |
| 无法定位 Codex，或发现多个宿主 | 打开目标 Codex 桌面应用；仍有歧义时让 Codex 检查，不另装 CLI 或随意选旧版本 |
| 网络访问或发行包校验失败 | 检查 GitHub 连接，将报错发回 Codex，按固定版本说明重试；不要跳过校验 |
| 安装源冲突 | 让 Codex 检查 Blackbox 安装源；若同一个 `personal` 源含其他插件，不删除整个源 |
| 安装完成但没有侧边栏入口或 Blackbox 工具 | 按上面的“插件尚未加载时”检查 MCP 实际启动错误；本地网页可用不代表入口已加载，不需要安装 Probe 插件 |
| `OSError`、拒绝访问或其他会话打不开 | 保留命令、退出码、错误阶段及可取得的 `errno` / `winerror`，对照实际解释器和状态目录；不清库、不改目录或关闭沙箱来掩盖失败 |
| 项目已启用但没有记录 | 检查 Hook 信任、运行配置与实际回执，必要时重载；不要以初始化成功代替采集验证 |

## 更新、停用与卸载

- **更新：** 先保存工作，并在 Codex 中让 Blackbox 停止阅读服务，再发送新版 README 的安装提示词。历史、阅读偏好和项目设置保留；需要重开时按提示继续。正在进行的长回合不保证无损热加载。
- **停用项目：** 在采集设置中停用指定项目，或让 `blackbox-review` 完成。关闭页面或停止阅读服务不会停用采集，停用不删除历史。
- **卸载：** 可先让 `blackbox-review` 将数据备份到仓库之外的新文件，再通过 Codex 插件管理卸载。普通卸载不删除本地历史、Python、Codex 或其他插件。

备份恢复、导出及隐私说明见[使用与隐私](../release/ALPHA-GUIDE.md)。

## 已验证到哪一步

.45 收紧会话准入，防止安装辅助终端产生额外记录；升级后旧身份缓存会重新核对，已有历史不自动删除。公开下载与隔离安装检查已具备，但干净电脑测试已暴露后台 Python 启动和会话访问问题，完整安装体验尚未通过验收。最低 Codex 版本及 API Key 登录模式也尚未完成专项验收。修复需用新候选包验证重启、新会话及真实记录，不能用开发机或 Probe 结果替代。支持范围和已知限制见[使用与隐私](../release/ALPHA-GUIDE.md#当前限制与反馈)。
